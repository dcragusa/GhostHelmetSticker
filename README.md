# GhostHelmetSticker

The shiny Ghost Helmet sticker requires you to get 6 helmet pickups, but there are only 5 in the game! 

This is a small BepInEx mod that lowers the requirement for the Ghost Helmet sticker to 2 helmets instead of 3. Thus, crafting the shiny sticker will only require a total of 4 helmet pickups.

## Installation

- Install BepInEx for Hardspace: Shipbreaker if you haven't already.
- Drop GhostHelmetSticker.dll into BepInEx/plugins/.
- Launch the game.
